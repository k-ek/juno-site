Juno privacy policy

Juno is a private tool used only by its owner, on the owner's own accounts.

  • What it accesses: with explicit consent, read-only access to the owner's Gmail (scope gmail.readonly). It cannot send, change or delete email.
  • How it is used: only to answer the owner's own requests (for example, finding a renewal date) and to create reminders in the owner's task list.
  • Where it goes: data is processed on the owner's own server. It is not sold, shared, or used for advertising, and is not used to train models.
  • Storage: email content is not stored beyond what is needed to answer a request. Access tokens are kept on the owner's server only.
  • Revoking: access can be revoked at any time from the Google Account security settings (Third-party apps).

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
